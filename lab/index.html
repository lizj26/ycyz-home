这张背景里没有一张图片

120 根金柱、3 圈细环、520 颗金尘、1 块红盘——全部由 Three.js 在运行时生成， 素材 0 KB，只多两个 JS。下面这张表是它和你原来的纯 CSS 首屏、以及一张等价渲染图的对比。

方案首屏传输可否动画任意分辨率失败时
纯 CSS 渐变（现在） 0 KB 几乎不行 是 无风险
一张渲染图（PNG/WebP） 40–300 KB 不行 放大发虚 仍在
Three.js 程序化（本页） 619 KB JS（可缓存 / 可与入场动画共用） 是，可交互 是，矢量 自动退回 CSS 视觉

哪些图能这样换，哪些不能

适合程序化渲染

  • 门户首屏氛围（本页）
  • 装饰用的环、光带、粒子、纹样
  • 图标（已经在用内联 SVG）
  • 节日彩蛋一类的一次性视觉

不值得换

  • 真实影像：校园夜景那张、蹭饭图原图——代码画不出来
  • 官方标识：120 校徽带校名与年份，重绘必失真
  • 游戏背景：2D canvas 里再挂一个 WebGL，性能不划算
  • 小尺寸位图：压一压就够了（见下方数据）

接入方式（如果决定采用）

<!-- 1. 首屏里加一层画布，放在内容之下 -->
<section class="hero">
  <div class="hero-3d"><canvas id="hero3d"></canvas></div>
  <div class="hero-inner">…</div>
</section>

// 2. 空闲时再加载 three.js（不在 <head> 里写死），加载完再挂载
requestIdleCallback(function(){
  load('assets/three.min.js', function(){
    load('assets/hero3d.js', function(){
      YCYEZ_HERO.mount(document.getElementById('hero3d'));   // 不支持 WebGL / 减少动效时返回 false
    });
  });
});
