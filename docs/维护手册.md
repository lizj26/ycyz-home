# 维护手册

本站没有构建步骤，改完文件刷新浏览器就能看到效果。这份手册覆盖日常会遇到的几类改动。

## 开始之前

在仓库根目录起一个静态服务：

```bash
python -m http.server 8000
```

浏览器打开 `http://127.0.0.1:8000/`，逐页点一遍，确认没有异常再提交。推送之后 Pages 需要半分钟到一分钟重建，本地有缓存时按 `Ctrl+F5`。

## 毕业留念：新增一届

毕业留念按届分卷，每年新增一卷，旧卷保留不动。新增一届涉及两个文件。

### 新建数据文件

把 `memory/data/2026.js` 复制为 `memory/data/2027.js`，替换其中的班级数据。文件必须以 `window.CLASS_DATA = {...}` 开头，变量名不能改，页面只认这个变量。

```js
window.CLASS_DATA = {
  "1": { regions: [
    ["陕西西安", [["WSQ"], ["WB"], ["HJH", "西安交通大学·西安"]]],
    ["北京",     [["ZXY", "清华大学·北京"]]]
  ]},
  "2": { regions: [ /* ... */ ] }
};
```

数据结构如下：

| 层级 | 含义 | 说明 |
| --- | --- | --- |
| `"1"` … `"16"` | 班级号 | 字符串形式的数字，对应 `class.html?cls=1` |
| `regions` | 该班的分地区名单 | 数组，顺序就是页面上城市出现的顺序 |
| `["陕西西安", [...]]` | 一个地区及其中的同学 | 地区名用于地图定位，写成「省+市」最稳妥 |
| `["WSQ"]` | 只有姓名首字母 | 旧数据常见写法，学校位置显示「去向见原图」 |
| `["HJH", "西安交通大学·西安"]` | 首字母加「学校·城市」 | 有这一段才能点击校名进官网，地图定位也才准确 |

几条约定：

- 人名只写拼音首字母。这是隐私底线，不要写真实姓名。
- 某个班名单尚未整理好时，把 `regions` 写成 `[]`，页面会显示「暂未开放」。
- 去向不确定的同学只写首字母，不要推测学校。
- 「学校·城市」中的城市要用地级市名，如 `·西安`、`·南京`，否则地图无法定位。

### 登记到届别清单

在 `memory/data/years.js` 的数组末尾追加一条：

```js
window.YCYEZ_YEARS = [
  { id: "2026", label: "2026届", file: "data/2026.js", note: "首届 · 高中三年完整经历疫情" },
  { id: "2027", label: "2027届", file: "data/2027.js", note: "第二届" }
];
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 网址参数，纯数字字符串，如 `"2027"`；`?year=2027` 可直接打开这一届 |
| `label` | 是 | 显示名称，如 `"2027届"` |
| `file` | 是 | 相对 `memory/index.html` 的路径，固定写 `data/2027.js` |
| `note` | 否 | 鼠标悬停在切换按钮上时显示的一句话 |

数组顺序即页面顺序，最后一项是默认打开的那一届，所以新届一定追加在末尾。只有一届时页面不显示切换条，两届以上才出现。

### 本地验证

打开 `http://127.0.0.1:8000/memory/`，确认：

- 标题、统计行、页脚都已切换到新届；
- 届别切换条出现，点击旧届能回到 2026；
- 任意点开一个班，班级页标题跟随届别变化，返回链接带有 `?year=` 参数。

### 常见问题

| 现象 | 原因 |
| --- | --- |
| 所有班级都显示「暂未开放」 | 数据文件未加载：路径写错、变量名不是 `CLASS_DATA`、或存在语法错误（漏逗号最常见）。浏览器控制台会给出行号 |
| 新届没有出现在切换条里 | `years.js` 漏了那一行，或 `file` 与实际文件名不一致 |
| 打开后仍是旧届 | `years.js` 中的顺序问题，默认打开的是最后一项 |
| 城市标到了错误的位置 | 「学校·城市」里的城市名不规范，或地区名只写了省份（如只写「陕西」） |

检查数据文件语法：

```bash
node --check memory/data/2027.js
```

## 大学资料：新增条目

只改 `university/data/links.js`。

新增一条，找到对应分组，在 `items` 数组末尾追加：

```js
{
  name: "名称",
  url: "https://example.com/",
  desc: "一句话说明它解决什么问题。",
  tag: "免费"
}
```

`name` 与 `url` 必填，`url` 须为 https 且能直接打开。`desc` 建议填写，过长会破坏排版。`tag` 可选，取值如「免费」「开源」「需注册」。

新增一个分组，在数组末尾追加：

```js
{
  group: "分组名",
  note: "显示在分组标题右侧的一句提示",
  items: [ /* 若干条 */ ]
}
```

收录原则写在文件开头，改动时不要删掉：

1. 只给入口，不镜像也不搬运内容，因此不涉及版权问题；
2. 优先官方站点与长期维护的仓库，短期活动页不收；
3. 新增后自己点开确认一次；
4. 分组不超过六个，单组条目不超过八条，超出之后就不再像一份目录了。

## 高中资料：开始收录

`highschool/data/links.js` 目前是空数组，页面显示「这里还空着」，这是预期状态。开始收录时，把文件开头注释里的示例取消注释并替换为真实内容，数据结构与大学资料一致。

另外几点：

- 只放自己整理的，或作者明确允许转载的资料，不要上传他人的教辅扫描件；
- 优先使用 GitHub 仓库或公开网盘链接，不要放需要申请权限才能打开的地址；
- 真题注明来源年份，试卷与答案分开标注；
- 资料量较大时建议单独开一个仓库（例如 `ycyz-materials`），本站只放链接，不承担大文件存储。

## 论坛上线后的接入

论坛是本站唯一需要后端的部分，代码在独立仓库（Flask + SQLite），目前未部署。

部署完成、拿到地址后，只需要改一个值：

```js
// assets/site.config.js
forumUrl: "https://forum.example.com/"
```

要求是 https，结尾带斜杠。改完之后：

- 门户首页的论坛卡片从「筹备中」变为「已上线」，点击直接进入论坛；
- 顶栏与页脚的论坛入口同步改为外链；
- `forum/index.html` 会自动跳转到新地址，旧链接不会失效。

`forumUrl` 留空时全站显示「筹备中」，不会出现死链，因此部署前保持为空即可。

上线前确认两件事：论坛数据有独立备份（SQLite 文件定时导出），以及至少一个管理员账号可以正常登录。

## 修改文案与视觉

| 要改的内容 | 位置 |
| --- | --- |
| 站点名、副标题 | `index.html` 顶部的 `<header>` 与 `<title>` |
| 首页「这里有什么」引导段 | `index.html` 中 `<section class="hero">` 与 `<div class="sec-head">` |
| 页脚免责声明 | 各页 `<footer>`，共五处（首页、404、论坛、高中、大学），需一起改；毕业留念的页脚是独立样式，单独处理 |
| 子页顶部提示 | 各页的 `<div class="tip">` 或说明段落 |
| 论坛版块说明 | `forum/index.html` 的 `<ol class="board-list">` |

所有颜色集中在 `assets/portal.css` 顶部的 `:root`：

```css
--red:#a9291c;      /* 主色·绛红 */
--gold:#c9973f;     /* 强调·鎏金 */
--bg:#faf4e8;       /* 纸底 */
--ink:#2b2320;      /* 正文 */
```

改动这几个变量，门户与子页会一起变化。`memory/` 使用独立的一套样式，有自己的 `:root`，不受影响；这一页的视觉是原有设计，保留即可。

字号与间距使用 `clamp()` 写法（如 `clamp(21px,2.8vw,27px)`），含义是随屏幕宽度缩放并带上下限。改动时保留这个写法，否则窄屏会挤。

## 问题排查

| 现象 | 检查方向 |
| --- | --- |
| 首页卡片点了没反应 | 控制台是否报错；`assets/site.config.js` 是否 404 |
| 子页样式全部丢失 | `assets/portal.css`、`assets/subpage.css` 的路径；部署时是否漏推 `assets/` |
| 大学或高中列表为空 | 对应的 `data/links.js` 加载失败，可能是路径或语法错误，控制台会给出行号 |
| 毕业留念白屏 | `memory/data/years.js` 到该届数据文件的链条断了一环 |
| 改了内容线上没变 | Pages 仍在构建（等一分钟），或浏览器缓存（`Ctrl+F5`） |
| 页面 404 | 文件名大小写。Pages 区分大小写，本地 Windows 不区分，这是最常见的一类事故 |
| 中文文件名 404 | 同上，路径建议全部使用英文小写 |
| 首屏没有金色柱阵 | 多数情况是主动跳过：视口窄于 1100px、系统开启「减少动态效果」、浏览器开启省流量、设备内存不超过 2GB，任一命中就不加载，首屏退回 CSS 视觉。加 `?force3d=1` 打开页面，能出现即说明是主动跳过 |
| 加了 `?force3d=1` 仍不出现 | 控制台是否有 `three.min.js` 404（该文件在 `memory/assets/` 下，与毕业留念共用，不要删除或改名）；再确认浏览器是否禁用了 WebGL |

## 提交前检查

- 本地逐页点过，控制台没有红色报错；
- 改过的 `.js` 都过一遍 `node --check`；
- 用 DevTools 切到 390px 宽度，页面没有横向滚动；
- 页面之间的跳转、返回首页的入口都能走通；
- 新增的链接自己点开确认过；
- 新增图片按显示尺寸出图，单张尽量控制在 60KB 以内；
- 首屏之外的图片带有 `loading="lazy"`；
- 没有把带真实姓名的原图或未脱敏素材提交进仓库。
