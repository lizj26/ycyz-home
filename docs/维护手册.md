# 维护手册

日常要改的东西基本集中在这几处。所有改动**改完刷新浏览器就能看到**，没有构建步骤。

## 0. 开工前

```bash
cd ycyz-home
python -m http.server 8000
# http://127.0.0.1:8000/
```

改完先在本地看，确认没问题再提交。提交后 Pages 需要 30 秒到 1 分钟重建，
浏览器有缓存时按 `Ctrl+F5` 强刷。

---

## 1. 毕业留念：加一届

毕业留念按「届」分卷，**每年加一卷，旧的一卷不删**。加一届只碰两个文件。

### 第 1 步：建数据文件

复制 `memory/data/2026.js` 为 `memory/data/2027.js`，把里面的班级数据整个换成新的。
文件必须以这一行开头，**变量名不能改**：

```js
window.CLASS_DATA = {
  "1": { regions: [
    ["陕西西安", [["WSQ"], ["WB"], ["HJH", "西安交通大学·西安"]]],
    ["北京",     [["ZXY", "清华大学·北京"]]]
  ]},
  "2": { regions: [ /* ... */ ] }
};
```

结构说明：

| 层级 | 含义 | 说明 |
|---|---|---|
| `"1"` … `"16"` | 班级号 | 字符串形式的数字，对应 `class.html?cls=1` |
| `regions` | 该班的分地区名单 | 数组，顺序 = 页面上城市出现的顺序 |
| `["陕西西安", [...]]` | 一个地区 + 该地区的同学 | 地区名用于地图定位，写「省+市」最稳 |
| `["WSQ"]` | 只有姓名首字母 | 老数据常见写法，学校显示为「去向见原图」 |
| `["WSQ", "西安交通大学·西安"]` | 首字母 + 「大学·城市」 | 有这一段才能点校名进官网、城市才精确 |

几点约定：

- **人名只用拼音首字母**，不要写真名，这是隐私底线；
- 某个班的名单还没整理好，`regions` 写成 `[]`，页面上那个班显示「暂未开放」；
- 某位同学的去向不确定就只写首字母，别猜学校；
- 「大学·城市」里的城市名要能被地图识别（写地级市，如 `·西安`、`·南京`）。

### 第 2 步：登记到届别清单

在 `memory/data/years.js` 的数组**末尾**追加一条：

```js
window.YCYEZ_YEARS = [
  { id: "2026", label: "2026届", file: "data/2026.js", note: "首届 · 高中三年完整经历疫情" },
  { id: "2027", label: "2027届", file: "data/2027.js", note: "第二届" }   // ← 新增
];
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 网址参数用，纯数字字符串，如 `"2027"`；访问 `?year=2027` 打开这一届 |
| `label` | 是 | 显示名，如 `"2027届"` |
| `file` | 是 | 相对 `memory/index.html` 的数据路径，固定写 `data/2027.js` |
| `note` | 否 | 鼠标悬停切换按钮时显示的一句话 |

**顺序 = 页面顺序，最后一项是默认打开的那一届。** 所以新届一定追加在末尾。
只有一届的时候页面不显示切换条，两届以上才出现。

### 第 3 步：本地验证

打开 `http://127.0.0.1:8000/memory/`：

- 标题、统计行、页脚是不是都变成了新届；
- 届别切换条有没有出现，点旧届能不能跳回 2026；
- 随便点一个班，班级页标题是不是跟着届别变，返回链接有没有带上 `?year=`。

### 常见错误

| 现象 | 原因 |
|---|---|
| 所有班级都显示「暂未开放」 | 数据文件没加载：路径写错、变量名不是 `CLASS_DATA`、或有语法错误（漏逗号最常见）。看浏览器控制台报的行号 |
| 新届没出现在切换条里 | `years.js` 里漏了那一行，或 `file` 路径与真实文件名不一致 |
| 打开还是旧届 | `years.js` 的顺序问题——默认打开的是**最后一项** |
| 城市落到了奇怪的位置 | 「大学·城市」里城市名不规范，或地区名写成了省份（如只写「陕西」）|

想快速自检语法，可以在项目根目录跑：

```bash
node --check memory/data/2027.js
```

## 2. 大学开源资料：加一条入口

只改 `university/data/links.js`。

### 加一条

找到对应分组，在 `items` 数组里追加：

```js
{
  name: "名称",                       // 必填，短一点
  url: "https://example.com/",        // 必填，https，必须能直接打开
  desc: "一句话说明它解决什么问题。",  // 建议写，太长会撑破排版
  tag: "免费"                          // 可选：免费 / 开源 / 需注册
}
```

### 加一个分组

在数组末尾追加：

```js
{
  group: "新分组名",
  note: "一句提示，显示在分组标题右侧",
  items: [ /* 若干条 */ ]
}
```

### 收录原则（写在文件开头，别破坏）

1. 只给**入口**，不镜像、不搬运内容——所以不涉及版权；
2. 优先官方站点和长期存在的仓库，短命的活动页别放；
3. 新增后**自己点一遍**，确认能打开；
4. 分组不要超过 6 个，单组条目不要超过 8 条，多了就不像目录了。

## 3. 高中开源资料：从空到有

`highschool/data/links.js` 现在是一个空数组（页面显示「这里还空着」），
这不是 bug。要开始收录，把文件开头注释里的示例取消注释、改成真实内容即可，
结构与大学资料完全一致。

额外注意：

- 只放**自己整理的**，或作者明确允许转载的；不要传别人的教辅扫描件；
- 优先 GitHub 仓库或公开网盘链接，别放需要申请权限的；
- 真题请注明来源年份，答案和试卷分开标注，别混着放；
- 资料放 GitHub 时建议单独开一个仓库（例如 `ycyz-materials`），
  这里只放链接，本站不承担大文件存储。

## 4. 论坛上线后怎么接

论坛是唯一需要后端的部分，代码在另一个仓库（Flask + SQLite），目前未部署。

部署拿到地址后，**只改一个值**：

```js
// assets/site.config.js
forumUrl: "https://forum.example.com/"   // 必须 https，结尾带斜杠
```

改完的效果：

- 门户首页的论坛卡片从「筹备中」变「已上线」，点击直接进论坛；
- 顶栏和页脚的「论坛」一起变外链；
- `forum/index.html` 自己会跳转到这个地址，旧链接不会失效。

`forumUrl` 留空时全站显示「筹备中」，**不会出现死链**，所以部署前保持空着就好。

上线前记得确认：论坛有独立的数据备份（SQLite 文件定时导出），
以及至少一个管理员账号能登录。

## 5. 改文案

| 想改什么 | 位置 |
|---|---|
| 站点名、副标题 | `index.html` 顶部 `<header>` 与 `<title>` |
| 首页三块「先说清楚几件事」 | `index.html` 的 `<section class="about">` |
| 页脚免责声明 | 各页 `<footer>`，共 5 处（首页 + 4 个子页） |
| 子页顶部的提示框 | 各页 `<div class="tip">` 或说明段落 |

改页脚时注意 5 个页面一起改，不然口径不一致。

## 6. 改视觉

所有颜色集中在 `assets/portal.css` 顶部的 `:root`：

```css
--red:#a9291c;      /* 主色·绛红 */
--gold:#c9973f;     /* 强调·鎏金 */
--bg:#faf4e8;       /* 纸底 */
--ink:#2b2320;      /* 正文 */
```

改这几个值，门户和所有子页一起变。`memory/` 是独立的一套样式（毕业留念页原有设计），
它有自己的 `:root`，不受这里影响——那是故意的，那一页的视觉是原作者的。

字号、间距用的是 `clamp()`（如 `clamp(21px,2.8vw,27px)`），意思是「随屏幕宽度缩放，
有上下限」，改的时候保留这个写法，不然手机端会挤。

## 7. 排查清单

| 现象 | 先查什么 |
|---|---|
| 首页卡片点了没反应 | 浏览器控制台有没有报错；`assets/site.config.js` 是否 404 |
| 子页样式全丢 | `assets/portal.css`、`assets/subpage.css` 路径；部署时是否漏推 `assets/` |
| 大学 / 高中列表是空的 | 对应 `data/links.js` 加载失败（路径或语法），控制台会报行号 |
| 毕业留念白屏 | `memory/data/years.js` → 该届数据文件的链条断了一环 |
| 改了内容线上没变 | Pages 还在构建（等 1 分钟）、或浏览器缓存（`Ctrl+F5`）|
| 页面 404 | 文件名大小写。GitHub Pages 区分大小写，Windows 本地不区分，**这是最常见的一类事故** |
| 中文文件名 404 | 同上，建议路径全用英文小写 |
| 首屏没有金色柱阵 | 正常，多数情况是**故意不加载**：窗口窄于 1100px、系统开了「减少动态效果」、浏览器开了省流量、设备内存 ≤ 2GB —— 任一命中就一个字节都不下载，首屏退回 CSS 视觉。要确认是不是这个原因，在网址后面加 `?force3d=1` 再打开：能出来就说明是主动跳过，不是坏了 |
| 加了 `?force3d=1` 也不出来 | 看控制台有没有 `three.min.js` 404（它在 `memory/assets/` 下，被毕业留念和首屏共用，**别删别改名**）；再看 WebGL 是否被浏览器禁用 |

## 8. 提交前自检

```
□ python -m http.server 8000 下逐页点过，控制台无红色报错
□ node --check 过所有改过的 .js
□ 手机宽度（DevTools 切 390px）下没有横向滚动
□ 页面之间的跳转、返回首页的入口都能走通
□ 新增链接自己点开确认过
□ 新增的图片按显示尺寸出图（42px 的徽标不要塞 512px），单张尽量 < 60KB
□ 首屏之外的图片带了 loading="lazy"
□ 没有把带真实姓名的原图、未脱敏素材提交进仓库
```
