全站只有这一块要后端。程序写完了，还差一台机器。上线之前先把样子说清楚。

现在点不进去，是还没部署，不是坏了。静态页不要钱，论坛得有个一直开着的服务器。

它会是什么样

按 2000—5000 人的规模设计，不是给十万人的
纯文字，不存图片 没有附件、头像、富文本。不用存文件，也少一堆麻烦。
邀请码注册 一码一人，管理员发。爬虫和外面的人进不来。
新号前 3 条需审核 过了前三条就不再审，老用户不用一直等。
有举报、有封禁 谁都能举报，处理有记录。帖子只有三种状态：待审、正常、隐藏。

五个版块

够用就行，不开一堆空版
  1. 01综合

    什么都聊。先从自我介绍开始。

  2. 02选课与教务

    选课、绩点、考试、培养方案。大一最需要的一个版。

  3. 03二手与拼单

    教材、电脑、拼车、拼单。留个联系方式，别被骗。

  4. 04失物招领

    丢了捡了都发这里，比群里刷屏强。

  5. 05技术与资源

    工具、脚本、教程，以及给资料站投稿。

为什么拖到现在还没上线

  1. 差一台机器。静态站能白嫖 GitHub Pages，论坛不行，得有常驻进程和一个数据库文件。
  2. 得有人看着。审核、发码、处理举报都是人的活，没人管很快就乱。
  3. 规则要先定。实名讨论和匿名吐槽是两回事，开版之前说清楚，比开了再补容易。
