首页/文字论坛

文字论坛 筹备中

全站唯一需要后端的部分。程序已经写完了，跑起来只差一台机器和一点运维耐心。 上线之前，这个页面用来交代它会是什么样子。

现在点不进去，是因为它还没部署，不是因为坏了。静态页面托管不花钱， 论坛要一台常年开着的服务器，这部分还在等条件。

它会是什么样

按 2000—5000 人的规模设计，不是给十万人的
纯文字，不存图片 没有附件、没有头像、没有富文本。省掉存储和审核的大半麻烦，也少了一堆内容风险。
邀请码注册 一码一人，由管理员发放。挡掉爬虫和外面的人，比答题验证有效。
新号前 3 条需审核 通过后自动免审。既拦住乱发，又不会让老用户一直等。
有举报、有封禁 谁都能举报，管理员处理留痕。内容只有三种状态：待审、正常、隐藏。

五个版块

够用就行，不开一堆空版
  1. 01综合

    什么都聊。先从自我介绍开始。

  2. 02选课与教务

    选课、绩点、考试、培养方案。大一最需要的一个版。

  3. 03二手与拼单

    教材、电脑、拼车、拼单。交易请留联系方式，注意安全。

  4. 04失物招领

    丢了捡了都发这里，比群里刷屏强。

  5. 05技术与资源

    工具、脚本、教程，以及给资料站投稿。

为什么拖到现在还没上线

  1. 要一台机器。静态站能白嫖 GitHub Pages，论坛不行，它得有个常驻进程和一个数据库文件。
  2. 要有人值守。审核、发码、处理举报，都是人的活。没人管的话论坛会烂得很快。
  3. 要想清楚边界。校内实名讨论和匿名吐槽是两回事，先定规则再开版，比开了再补规矩容易。

条件具备之后，维护者只需在 assets/site.config.js 里填一个地址， 全站所有论坛入口会同时变成可点的外链，不需要改页面。
