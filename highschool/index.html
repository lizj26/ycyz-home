打算放什么

各科笔记 手写扫描或者整理的电子版，按科目和年级分。
真题与模拟题 写上来源和年份，有答案的标一下全不全。
讲义与专题 老师发的专题、竞赛入门、自招强基的材料。
学法与避坑 怎么排时间、哪本书没用、高三哪些弯路可以绕开。

想放东西进来？

  1. 把资料传到 GitHub 仓库或公开网盘，拿到一个长期有效的链接。
  2. 打开 highschool/data/links.js，按文件开头的注释加一条，写明名称、链接、说明、来源。
  3. 不会改代码的话：论坛开了以后在「技术与资源」版发帖，或者直接找维护者。
  4. 别传别人的教辅扫描件。自己整理的，或者作者允许转载的，才能放。
